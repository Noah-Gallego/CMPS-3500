# CMPS 3500

Programming-languages coursework covering syntax, semantics, types, memory, paradigms, concurrency, and language implementation exercises.

## Course context

The repository preserves assignments for CMPS 3500 at California State University, Bakersfield, Spring 2025. The original course notes identify Linux/Odin, GNU tools, Git, and VS Code as the working environment.

## Contents

- `act01/` — C++ exercises
- `act02/` — Fortran exercises
- `act03/` — Perl, regular expressions, and text-processing exercises
- `act04/` — Ada exercises
- `act05/` — Ruby exercises
- `act07/` — Python exercises
- `act08/` — Common Lisp exercises
- `final/` — Los Angeles crime-data exploratory analysis notebook and data

The materials include examples of procedural, object-oriented, functional, and logic-oriented programming.

## Usage

Each activity directory contains its own source files and may include a Makefile or input files. Use the language-specific toolchain and inspect the local files before running an exercise. For the C++ activity, for example:

```bash
cd act01
make
```

Other activities use their respective compilers or interpreters; no single repository-wide build command is defined.
